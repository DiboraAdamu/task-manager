# Persistent Task Manager

A responsive, feature-rich to-do list web application built as a JavaScript capstone project focusing on arrays, objects, and ES6 features[cite: 1].

## Features
- **Add Tasks**: Type a new task and add it instantly via button click or the Enter key[cite: 1].
- **Mark Complete / Undo**: Toggle tasks between active and completed states[cite: 1].
- **Delete Tasks**: Remove individual tasks from the list[cite: 1].
- **Filter Views**: Switch seamlessly between **All**, **Active**, and **Done** tasks[cite: 1].
- **Live Counter**: Real-time tracking of active vs. total tasks[cite: 1].
- **Data Persistence**: Uses `localStorage` so your tasks remain saved even after refreshing the page[cite: 1].
- **Clear Completed**: Quickly clear out all finished tasks at once[cite: 1].

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+ array methods, DOM manipulation, localStorage)

## How to Run
1. Clone or download this repository to your local machine.
2. Open the `index.html` file in any modern web browser[cite: 1].
